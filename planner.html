Analog simulation planner

Compare the shape of a Mars or Moon terrain patch with measured Earth elevation.

Image mode estimates the relative depth of the center square. Use a measured elevation grid to compare real slopes and heights.

Files stay in your browser. Image mode downloads a depth model on first use.

Elevation grid format

Upload JSON with size (33–129), widthMetres, heightMetres, and values (row-major elevations in metres). Use a terrain patch close to 8 km across. If you resampled the grid, include nativeResolutionMetres to preserve the original sampling limit.
